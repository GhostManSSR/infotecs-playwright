# Задача 2: Автоматизация тестирования сайта ИнфоТеКС

## Требования к заданию

- **Язык**: JavaScript или TypeScript с использованием Playwright и Node.js/Bun
- **Архитектура**: Реализация с использованием паттерна **Page Object Model (POM)**
- **Браузер**: Chromium в режиме headless с viewport 1920×1080
- **Отчет**: HTML-отчет по результатам выполнения теста

## Описание задания

### Сценарий тестирования:

#### 1. Перейти на сайт https://infotecs.ru/

#### 2. Раскрыть раздел "О компании" и проверить наличие следующих вкладок:
- a. Компания «ИнфоТеКС»
- b. Экосистема ИнфоТеКС
- c. Лицензии
- d. Академия
- e. Патенты
- f. Акционерам
- g. Реквизиты
- h. Вакансии
- i. Контакты
- j. Информационные материалы

#### 3. Перейти в раздел: Главная → О компании → Патенты

#### 4. Проверить сумму значений категорий патентов:
Верификация, что сумма следующих значений равна общему значению:
- Патенты РФ на изобретения
- Свидетельства на продукты
- Свидетельства на товарные знаки
- Патенты РФ на промышленные образцы

**Результат**: Сумма должна быть равна общему значению "Патент"

## Проект


## Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Запуск тестов

```bash
npm test
```

### Просмотр отчета

После запуска тестов HTML-отчет будет доступен в папке `playwright-report/`. Чтобы открыть отчет:

```bash
npm run report
```

## Конфигурация

### playwright.config.ts

Конфигурация содержит следующие параметры:
- **Браузер**: Chromium
- **Режим**: headless (без GUI)
- **Viewport**: 1920×1080
- **Timeout**: 30 секунд на действие
- **Retries**: 0 попыток при разработке

## Page Object Model (POM)

### BasePage.ts
Базовый класс, содержащий общие методы для всех страниц:
- Навигация
- Ожидание элементов
- Клики по элементам
- Получение текстового содержимого

### HomePage.ts
Класс для работы с главной страницей infotecs.ru:
- Открытие сайта
- Навигация к разделу "О компании"
- Проверка наличия вкладок в разделе "О компании"

### PatentsPage.ts
Класс для работы со страницей "Патенты":
- Получение значений отдельных категорий патентов
- Получение общего значения патентов
- Верификация суммы категорий

## Технологический стек

- **TypeScript**: Строгая типизация кода
- **Playwright**: Автоматизация браузера
- **Node.js**: Среда выполнения
- **HTML Reporter**: Встроенный HTML-отчет Playwright

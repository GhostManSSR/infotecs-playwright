# Тестирование сайта ИнфоТеКС

Автоматизированный тест сайта [https://infotecs.ru/](https://infotecs.ru/) с использованием:

- Node.js
- TypeScript
- Playwright
- Chromium
- Page Object Model (POM)
- Docker
- GitHub Actions
- GitHub Packages

## Установка зависимостей

Переходим в нужную директорию:

```bash
cd task_2
```

Для установки зависимостей проекта выполнить:

```bash
npm ci
```

Для локального запуска также необходимо установить Chromium для Playwright:

```bash
npx playwright install chromium
```

## Локальный запуск тестов

Для запуска тестов выполнить:

```bash
npm test
```

Тест запускается в браузере Chromium в headless-режиме с viewport 1920x1080.

## HTML-отчёт

После выполнения тестов HTML-отчёт сохраняется в директории:

```text
playwright-report/
```

Для открытия HTML-отчёта выполнить:

```bash
npx playwright show-report
```

Дополнительные результаты выполнения тестов сохраняются в:

```text
test-results/
```

В этой директории могут находиться скриншоты, видео и trace-файлы при ошибках тестов.

## Запуск тестов в Docker

Сначала необходимо собрать Docker-образ в корневом каталоге:

```bash
docker build -f task_3/Dockerfile -t playwright-tests . 
```

После успешной сборки запустить контейнер:

```powershell
docker run --rm -v "${PWD}/playwright-report:/app/playwright-report" -v "${PWD}/test-results:/app/test-results" infotecs-playwright
```

Контейнер автоматически запускает тесты без ручного вмешательства.

После завершения тестов контейнер завершается с exit-кодом, соответствующим результату выполнения тестов:

- `0` — тесты успешно пройдены;
- ненулевой код — тесты завершились с ошибкой.

## Проверяемый сценарий

Тест выполняет следующие действия:

1. Переходит на сайт https://infotecs.ru/.
2. Раскрывает раздел «О компании».
3. Проверяет наличие следующих пунктов:
    - Компания «ИнфоТеКС»
    - Экосистема ИнфоТеКС
    - Лицензии
    - Академия
    - Патенты
    - Акционерам
    - Реквизиты
    - Вакансии
    - Контакты
    - Информационные материалы
4. Переходит в раздел «О компании → Патенты».
5. Получает количество патентов по отдельным категориям.
6. Складывает значения категорий.
7. Сравнивает полученную сумму с общим количеством патентов.

Проверяемое условие:

```text
Патенты РФ на изобретения
+ Свидетельства на продукты
+ Свидетельства на товарные знаки
+ Патенты РФ на промышленные образцы
=
Общее количество патентов
```

## Page Object Model

Проект реализован с использованием паттерна Page Object Model (POM).

`BasePage.ts` — базовый класс для страниц проекта.

`HomePage.ts` — содержит логику работы с главной страницей и разделом «О компании».

`PatentsPage.ts` — содержит логику работы со страницей патентов и проверки количества патентов.

`tests/infotecs.spec.ts` — содержит основной автоматизированный тестовый сценарий.

## CI/CD

Для автоматического запуска тестов используется GitHub Actions.

Конфигурация pipeline находится в файле:

`ci.yml`

Pipeline состоит из двух этапов:

```text
playwright-tests
  ↓
publish-image
```

### Этап test

```text 
1) Запускает Docker-in-Docker.
2) Собирает Docker-образ проекта.
3) Выполняет DNS-проверку сайта infotecs.ru.
4) Выполняет HTTPS-проверку сайта.
5) Создаёт Docker-контейнер с Playwright-тестами.
6) Автоматически запускает тесты в Chromium.
7) Получает exit-код контейнера.
8)Копирует HTML-отчёт из контейнера.
9) Копирует результаты тестирования.
10) Загружает отчёты в GitHub Artifacts.
```
### Этап publish

Этап publish запускается только после успешного выполнения этапа test.

На этом этапе Docker-образ проекта загружается в GitHub Packages.

```text
latest
